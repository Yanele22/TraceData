# TraceData 🕵🏾‍♀️
*Every Dataset Leaves a Clue.*

TraceData is a cloud-powered data engineering mystery game where users investigate financial datasets, uncover hidden anomalies, and solve cases using data pipelines and analytical SQL.

## 🎯 Case #001: The Missing Money
A series of unauthorized transfers drained **R50,000** from corporate accounts. Your goal is to engineer the pipeline, process the raw evidence, and run forensic queries to identify the suspect.
